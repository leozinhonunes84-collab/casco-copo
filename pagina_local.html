Atalhos do projeto

Painel local Abre o painel Python com ajuste de preco, cadastro montavel, liberacao e gerador.
Auditoria API Consulta o cardapio ZigPay e compara produtos com os valores da planilha.
Dashboard Usa Playwright para operar rotinas que nao estao documentadas na API.
Importacao Gera Excel para cadastrar produto novo ou produtos existentes no ZigPay.
Abrir painel Ver HTML atual

Para o botao do painel funcionar, rode o servidor local com o comando abaixo.

Comandos rapidos

.\run_panel.ps1
python auditar_precos_api.py
pip install -r requirements.txt
